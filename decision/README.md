# decision/ — журнал изменений агента

Каталог кратких записей о проделанной работе (что, зачем, какие файлы, чем
проверено). Правила заполнения — [`.roo/rules-code/04-decision-log.md`](../.roo/rules-code/04-decision-log.md).

## Конвенция

- Один файл на задачу/сессию: `YYYY-MM-DDTHH-mm-<slug>.md` (время **UTC**).
  Пример: `2026-10-26T18-05-fix-report-writer.md`.
- Записи только добавляются, существующие не редактировать задним числом.
- Содержимое — по шаблону из файла правила: «Что сделано / Зачем /
  Затронутые файлы / Проверка / Риски».

## Назначение

Следующий агент или инженер может прочитать историю решений, не разбирая
весь git-diff, и понять контекст текущих изменений.
